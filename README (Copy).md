# Recurrence quantification analysis with surrogate-based testing and Augmented Dickey-Fuller unit-root tests on the Philippine Stock Exchange Index
### by John Carlo Elmaguin, Romie Mabborang, Jennifer Sy, Gerard Estoperez, Karen Quola Rubio

## Abstract
We investigate the long-term dynamics of the Philippine Stock Exchange Index (PSEi) from 2000 to 2024. Using monthly observations, we assess whether the index exhibits statistically detectable low-dimensional deterministic structure or is consistent with a linear stochastic process. Two complementary approaches are employed: (i) recurrence quantification analysis (RQA) combined with hypothesis testing using iterative amplitude adjusted Fourier transform (IAAFT) surrogates, and (ii) the Augmented Dickey–Fuller (ADF) unit-root test. RQA quantifies recurrent structures, providing a nonlinear perspective that complements the linear unit-root framework of the ADF test. Our results show that raw recurrence measures exhibit elevated determinism, laminarity, and Shannon entropy of diagonal length distributions, features that are often associated with deterministic dynamics. However, surrogate-based hypothesis testing fails to reject the null hypothesis of a linear stochastic process. Consistently, the ADF test indicates the presence of a unit root. These findings suggest that apparent nonlinear signatures in the PSEi are not statistically distinguishable from linear stochastic behavior, highlighting the importance of surrogate validation in nonlinear time series analysis and reinforcing stochastic modeling assumptions commonly used in financial markets.

## Overview
This repository contains the data and code used to analyze the long-term dynamics of the Philippine Stock Exchange Index (PSEi) using Recurrence quantification analysis with surrogate-based testing and Augmented Dickey-Fuller unit-root tests on the Philippine Stock Exchange Index.

## Implementation

### RQA with IAAFT surrogate-based hypothesis testing
All source code used to generate the results and figures in the paper for the RQA implementation is in the `RQA` folder. The data used in this study are provided in `psei.csv`. The Python source code is `stocks.ipynb`. The calculations and figure generation are all run inside a Jupyter notebook. Execute the Jupyter notebook individually. To do this, you must first start the notebook server by going into the repository's top level and running (make sure you have Jupyter Notebook installed):

 > jupyter notebook

Results generated by the code are saved in `test_output`, including the figures, DET, LAM, ENTR, and if the null hypothesis is rejected for each embedding dimension. All generated surrogate data sets are saved in the `surro_index` folder. The selection of time delay, embedding dimensions, and the generation of surrogates via TISEAN v.3.0.0 are also integrated in the RQA source code.
