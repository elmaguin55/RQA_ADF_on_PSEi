# RQA
recurrence quantification analysis for sites 1-5

python notebook filename: RQA.ipynb

RP are located at n/RP, time-series curve at n/LC, and surrogate test curves are located at n/surro. Make sure that you have pyUNICORN and matplotlib installed

Summary of the surrogate data: The data are all deterministic. The embedding dimensions used are m=3, t=9. with threshold distance equal to epsilon = 0.6

Note that if codes are executed, surrogate dataset (all 195 datasets) will be generated on the "files" folder
