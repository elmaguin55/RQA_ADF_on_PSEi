# Recurrence quantification analysis with surrogate-based hypothesis tests and Augmented Dickey-Fuller unit-root tests on the Philippine Stock Exchange Index
### by John Carlo Elmaguin, Romie Mabborang, Jennifer Sy, Karen Quola Rubio

## Abstract
We investigate the Philippine Stock Exchange Index's (PSEi) long-term dynamics from January 2000 to December 2024.  Using monthly observations, we assess whether the index exhibits statistically detectable structure beyond a linear Gaussian process. Two complementary approaches are employed: (i) recurrence quantification analysis (RQA) combined with wavelet-based iterative amplitude-adjusted Fourier transform (WIAAFT) and pseudo-periodic (PPS) surrogate-based hypothesis tests, and (ii) the Augmented Dickey-Fuller (ADF) unit-root test. RQA offers a nonlinear perspective on recurrence patterns that complements the ADF test's linear unit-root framework. WIAAFT surrogate testing provides evidence of deviation from simple linear dynamics by rejecting the null hypothesis of a linear Gaussian process. However, the PPS test fails to reject its null hypothesis, suggesting that the detected nonlinear structure remains statistically indistinguishable from a noisy pseudo-periodic process.   Elevated laminarity and entropy (ENTR) metrics reflect periods of prolonged state persistence and highly variable recurrent timescales, respectively. These geometric features suggest regularities in the phase space that resemble intermittency. Overall, the results highlight the importance of surrogate validation in time series and provide evidence that the PSEi is nonstationary in the linear framework yet exhibits a statistically detectable nonlinear structure consistent with intermittent pseudo-periodic dynamics masked by uncorrelated noise.

## Overview
This repository contains the data and code used to analyze the long-term dynamics of the Philippine Stock Exchange Index (PSEi) using Recurrence quantification analysis with surrogate-based tests and Augmented Dickey-Fuller unit-root tests on the Philippine Stock Exchange Index.

## Implementation
### Execution flow
1. Run `stocks.ipynb` (Python): computes AMI, FNN, RQA measures, create figures as presented in the paper
2. Julia scripts (`PP.jl` and `WIAAFT_srrogates`) are called automatically in `stocks.ipynb` for surrogate generation
3. Run ADF.R (R): performs linear unit‑root tests. KPSS and PP test are also included. 

### RQA with surrogate-based hypothesis tests
All source code used to generate the results and figures in the paper for the RQA implementation is in the `RQA` folder. The data used in this study are provided in `psei.csv`. The Python source code is `stocks.ipynb`. The calculations and figure generation are all run inside a Jupyter notebook. Execute the Jupyter notebook individually. To do this, you must first start the notebook server by going into the repository's top level and running (make sure you have Jupyter Notebook installed):

 > jupyter notebook

Results generated by the code are saved in `test_output`, including the figures, DET, LAM, ENTR, and if the null hypothesis is rejected for each embedding dimension. All generated surrogate data sets are saved in the `surro_index` folder. The selection of time delay, embedding dimensions, and the generation of surrogates via TISEAN v.3.0.0 are also integrated in the RQA source code.
