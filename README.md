# Recurrence quantification analysis with surrogate-based hypothesis tests and Augmented Dickey-Fuller unit-root tests on the Philippine Stock Exchange Index
### by John Carlo Elmaguin, Romie Mabborang, Jennifer Sy, Gerald Estoperez, Karen Quola Rubio


## Overview
This repository contains the data and code used to analyze the long-term dynamics of the Philippine Stock Exchange Index (PSEi) using Recurrence quantification analysis with surrogate-based tests and Augmented Dickey-Fuller unit-root tests on the Philippine Stock Exchange Index. WIAAFT surrogate-based test rejects the linear Gaussian null hypothesis for DET, LAM, and ENTR, providing statistical evidence against linear dynamics. PPS surrogate-based test fails to reject the pseudo-periodic null hypothesis for DET, LAM, and ENTR, indicating dynamics consistent with noisy pseudo-periodicity. ADF, KPSS, and PP tests consistently indicate unit-root nonstationarity in the PSEi in the linear framework. Overall, the results indicate that the PSEi is nonstationary under linear ADF tests while exhibiting statistically detectable nonlinear structure consistent with intermittent pseudo-periodic dynamics masked by uncorrelated noise.


## Implementation
### Execution flow
Tested on a Unix‑like operating system (Ubuntu 24.04 LTS)
1. Run `stocks.ipynb` (Python): computes AMI, FNN, RQA measures, create figures as presented in the paper
2. Julia scripts (`PP.jl` and `WIAAFT_srrogates`) are called automatically in `stocks.ipynb` for surrogate generation
3. Run ADF.R (R): performs linear unit‑root tests. KPSS and PP test are also included. 

### RQA with surrogate-based hypothesis tests

All source code used to generate the results and figures in the paper for the RQA implementation is in the `RQA` folder. The data used in this study are provided in `psei.csv`. The Python source code is `stocks.ipynb`. The calculations and figure generation are all run inside a Jupyter notebook. Execute the Jupyter notebook individually. To do this, you must first start the notebook server by going into the repository's top level and running (make sure you have Jupyter Notebook installed):

Results generated by the code are saved in `test_output` folder, including the figures. The DET, LAM, ENTR, and if the null hypothesis is rejected for each embedding dimension are stored in `stock_PP` and `stocks_WIAAFT` text files, for both PPS and WIAAFT surrogate test, respectively. All generated surrogate data sets are saved in the `surro_index` folder. The selection of time delay and embedding dimensions via TISEAN v.3.0.0 are also integrated in the RQA source code.
